## 목적

**내가 아는 내용을 직접 말로 전달할 수 있게 하는 것이 최종 목표다.**

면접에서 어떤 질문을 만났을 때 직접 설명할 수 있어야 한다. 특히 내 언어로 코멘트를 남겨야 직접 대답할 수 있다고 생각한다. 따라서 AI로 학습하는 것은 허용하지만, 코멘트는 직접 작성한다. 코멘트 자체를 AI에게 다듬어 달라고도 하지 않는다. 내가 직접 코멘트를 작성해야 한다.

## 26기 참여자와 발제 순서

| 팀 | 구성원 | 발제 주기 |
| --- | --- | --- |
| A팀 | 구가영, 송우민, 황재무 | 1주차, 3주차, 5주차… |
| B팀 | 김민오, 이예은, 이은지 | 2주차, 4주차, 6주차… |

팀은 매주 교대합니다. 한 주의 발제 팀은 월요일 00시에 시작하며, 각 팀원은 그 주에 하나의 주제를 발제합니다.

## 진행 방식

1. 발제자는 월요일 00시 이전까지 GitHub Discussion에 주제를 등록합니다.
2. 모든 참여자는 해당 주제에 대해 학습하고, 그 주의 일요일 23:59(KST)까지 자신의 코멘트를 작성합니다.
3. 발제자 본인의 주제도 다른 참여자와 동일하게 코멘트 대상에 포함합니다.
4. 코멘트는 자신의 언어로 직접 작성합니다. 학습 과정에서 AI를 사용하는 것은 허용하지만, 코멘트 자체를 AI가 작성하거나 다듬도록 맡기지는 않습니다.
5. 한 주가 끝나면 자동 점검이 실행되어 미작성 주제 수와 누적 벌금을 이 표에 반영합니다.

## 주간 벌금 현황

> 마지막 자동 점검: `2026-09-14 00:00 (KST)`
>
> 코멘트 1건 미작성당 `3,000원`입니다. 전주 미작성 건을 이번 주에도 해결하지 않으면 이월 건으로 다시 1건을 부과합니다. 이후 코멘트를 작성하면 해당 이월 건은 다음 점검부터 제외됩니다.

| 참여자 | 이번 주 미작성 | 이월 미작성 | 이번 주 부과액 | 누적 벌금 |
| --- | ---: | ---: | ---: | ---: |
| 구가영 | 0 | 0 | 0원 | 0원 |
| 송우민 | 0 | 0 | 0원 | 0원 |
| 황재무 | 0 | 0 | 0원 | 0원 |
| 김민오 | 0 | 0 | 0원 | 0원 |
| 이예은 | 0 | 0 | 0원 | 0원 |
| 이은지 | 1 | 0 | 3,000원 | 3,000원 |

## 자동 점검

GitHub Actions의 `주간 벌금 점검` 워크플로가 매주 일요일에서 월요일로 넘어가는 자정(KST)에 실행됩니다. GitHub Actions의 스케줄은 UTC 기준이므로 `일요일 15:00 UTC`로 설정되어 있습니다.

워크플로는 **2026년 9월 7일 이후에 개설된 GitHub Discussions**만 점검 대상으로 삼습니다. 해당 주의 발제와 코멘트를 확인하고, `data/fines-state.json`에 누적 상태를 저장한 뒤 README의 현황 표를 갱신합니다. 2026년 9월 7일 주간은 A팀부터 시작하며 이후 매주 A/B팀이 교대합니다. 저장소 설정에서 Actions가 `Read and write permissions`를 사용하도록 허용해야 README 커밋이 가능합니다.

참여자의 GitHub 로그인 아이디는 [`data/participants.json`](data/participants.json)에 등록해야 합니다. 이름만으로는 GitHub API의 작성자를 안정적으로 식별할 수 없기 때문입니다.

수동으로 즉시 실행하려면 Actions 탭에서 `주간 벌금 점검`을 선택한 뒤 `Run workflow`를 누릅니다.

## 이상적인 스터디 방향

- **해당 스터디에 시간을 쏟는 시간은 하루 30분이 이상적입니다.**
  - 해당 주제를 공부하는 과정에서 너무 깊이 있게 들어가 시간이 뺏기지 않도록, 하루 공부 시간이 30분을 넘지 않도록 하는 것이 이상적입니다.
  - 해당 주제가 관심이 가고 중요하다고 생각한다면 30분 이상 학습하는 것은 본인의 자유입니다. 다만 매일 진행하는 스터디인 만큼 부담이 가지 않도록, 이상적인 학습 시간은 30분으로 제한합니다.
- **코멘트 작성에는 AI를 사용하지 않습니다.**
  - 학습에 AI를 사용하는 것은 허용합니다. 다만 코멘트는 직접 작성합니다.
  - 본 스터디의 목적은 해당 질문을 면접이나 다른 사람에게 설명해야 할 때 내 언어로 직접 답변하는 것입니다. 내가 직접 다른 사람에게 설명한다는 마음으로 코멘트를 작성해야 합니다.
  - 그래야 나중에 면접에서도 대답할 수 있습니다.
- 주제에 대한 코멘트 작성 방향은 **면접 대비 및 학습 정리**에 초점을 둡니다.
